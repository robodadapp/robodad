# Music in RoboDad: where every track comes from

Keep this file up to date whenever a track is added, so there is always a record of the right to use it.

## Made in the app (no files, no licences)

Everything in `static/radio.js` is synthesised live in the browser with the Web Audio API. No recordings and no samples are used.

| Track | Where it plays | Source |
|---|---|---|
| RoboDad Radio stations | Chill > Radio, Tile Talk | Original, except Canon in D (Pachelbel, public-domain composition, our own rendition) |
| `chess-*` loops | Chess, one per dad | Original |
| `chess-gamer` | Chess vs Gamer Dad | Original drift-phonk beat. Every sound is an oscillator or noise: no samples, no vocal chops |
| `chess-grandpa` | Chess vs Robo-Grandpa | "In the Hall of the Mountain King", Edvard Grieg (1843-1907), composed 1875. The composition is in the public domain. The 8-bit arrangement is RoboDad's own and no one else's recording, MIDI file or arrangement was used |
| Victory jingles | End of a won game | Original |
